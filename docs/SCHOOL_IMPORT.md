# Уточнённая школьная книга и компактные подгруппы

Реализован отдельный режим **сверки исходников**: «Проект → Школьная книга и
кабинеты». Выберите XLSX, затем DOCX кабинетов (можно пропустить). После просмотра
кнопка сохранения добавляет источник в текущий проект, не заменяя его базовое или
дневное расписание. Повторный просмотр: «Открыть сохранённую сверку».
Источники включаются в переносимый проект `.tlabs` вместе с историей.

Это адаптер конкретного формата уточнённой книги, а не произвольного Excel.
Сохранение источника не подтверждает назначения и не разрешает публикацию.
Перенос полностью сверенных событий в рабочую модель, сопоставление составов групп
и формы массового назначения преподавателей/кабинетов ещё предстоит реализовать.

## Отображение

- Класс занимает одну строку, временная сетка — дни и уроки по горизонтали.
- Две подгруппы делят высоту одного слота на две полосы; новых столбцов и
  увеличения ширины из-за деления на две нет.
- Три профиля делят высоту на три полосы. В общем недельном виде временная ось
  остаётся одинаковой для всех классов; читабельность обеспечивается высотой и
  масштабом. Слабое расширение для трёх допускается геометрией карточек, но в
  общем обзоре не требуется, чтобы не нарушать выравнивание времени.
- Общий урок — одно событие и одна карточка на все соответствующие полосы.
  Если объединены два из трёх профилей, карточка занимает две полосы; отдельный
  третий профиль остаётся самостоятельным событием. Совпадение названия предмета
  само по себе не объединяет занятия.
- Каждая карточка имеет свою заливку. Подробности, кандидаты преподавателей,
  вопросы и ссылки на строки источника доступны через наведение/двойной щелчок.
- В основном редакторе также заменено склеивание текстов на отдельные полосы;
  мышь выбирает и перетаскивает конкретную подгруппу.

## Правила разбора

Основной источник — «Группы — записи». Словарь названий — «Сокращения».
Объединение опирается на явный тип события и ответы листа «Вопросы по подгруппам».
Ответы о разных учителях истории/обществознания учитываются отдельно от цветов.
Для неизвестных преподавателей кандидаты из «Учителя — снимок» остаются
предложениями, даже если кандидат один. Цвет не подтверждает личность.

Если вопрос не имеет ответа, исходные карточки не объединяются догадкой.
Одна исходная строка всегда сохраняется в происхождении ровно одного события;
ID детерминированы и не меняются при повторном чтении того же файла.

Закрепления кабинетов из DOCX — предпочтения. Повторённые Word-блоки не создают
дубликатов. Фамилии без инициалов не связываются автоматически. Вместимость,
оснащение и фактические кабинеты занятий не выдумываются.

## Проверка на переданных файлах

- 10 листов, 1167 исходных строк занятий.
- 25 классов, 40 преподавателей в снимке.
- 861 единое событие с учётом уточнения пользователя после объединения общих занятий; сохранены все 1167 ссылок
  на строки, потерь и двойного использования строк не обнаружено.
- У 26 событий преподаватель подтверждён: 16 событий технологии, 8 из ответов
  по истории/обществознанию и 2 события биологии из уточнения пользователя.
- Разобраны 29 кабинетов и 29 закреплений, включая дополнительные кабинеты
  преподавателей 11 класса.
- В листе вопросов 13 записей. Последний вопрос — биология 11 класса, понедельник,
  шестой урок — разрешён уточнением пользователя: соцгум и физмат вместе у
  Голованёва, химбио отдельно у Харченко Е. П. В архиве два события; у общего
  события один ID и две несмежные полосы, верхняя и нижняя.

Исходные школьные файлы и нормализованные персональные данные не включены в Git:
адаптер и тесты используют синтетические примеры. Отчёт и переносимый проект с
вашими данными создаются отдельно в каталоге артефактов среды.

## Порядок профилей и ручные уточнения

Подтверждённый пользователем порядок сверху вниз:

- 11 класс: соцгум, химбио, физмат.
- 10а: соцгум, химбио.
- 10б: единый физмат без деления.

В двойном щелчке по слоту доступно ручное уточнение: профили с одинаковым номером
занятия объединяются, преподаватель выбирается из списка. Для несмежных профилей
сохраняются один ID и несколько связанных полос с обозначением ↔; средняя полоса
другого занятия остаётся на месте. Изменения сохраняются в источник только после
кнопки сохранения всей сверки. При отмене исходная копия не меняется.
Повторный импорт той же книги в проекте воспроизводит сохранённые уточнения по
SHA-256 исходника; другая книга автоматически этих решений не наследует.

Чтобы использовать переданный готовый файл `TimeLabs-school.tlabs`, выберите
«Проект → Импорт проекта», затем «Открыть сохранённую сверку». Поскольку это
переносимый проект, импорт заменяет текущий проект с предварительной копией.
Новые подтверждения из чата хранятся в этом файле, исходный XLSX остаётся неизменным.
